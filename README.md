LIBRARY MANAGEMENT SYSTEM📚
*a menu driven library management system built using python

##FEATURES✨
-Add books
-Remove books
-Search books
-Issue books
-Return books
-Display all books
-Save book details to a file
-load previously saved books
-handle exceptions and invalid inputs

##CONCEPTS USED
-OOPs
-File handling
-While loop
-For loop
-Exception handling
-List

##DATA STORAGE
Book details are stored in book.txt so it can be loaded again when the program starts.

##Author
a beginner project created by python for learning and practicing OOPS.
